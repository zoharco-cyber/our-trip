# הטיול שלנו

אתר לטיול משותף: כסף משותף, קניות לשבוע, חלומות, מסמכים שזמינים גם בלי אינטרנט, קפסולת זמן, מפה עם תמונות וסיפורים, גלריה, רשימת ציוד, ספירה לאחור ומדריך יעדים.

האתר חינמי לגמרי: הקוד והאתר יושבים ב-GitHub Pages, והנתונים, הקבצים וההתחברות ב-Supabase (בחבילה החינמית).

## הקמה (פעם אחת)

### 1. Supabase
1. נרשמים ב-supabase.com ופותחים פרויקט חדש (Free). אזור מומלץ: Frankfurt.
2. **SQL Editor > New query**, מדביקים את כל התוכן של `supabase/schema.sql` ולוחצים **Run**. אחר כך אותו דבר עם הקבצים `supabase/v2.sql` עד `supabase/v15-status.sql`, לפי הסדר.
3. **Authentication > Sign In / Providers > Email**: מכבים את **Confirm email**.
4. **Authentication > Users > Add user > Create new user**, ומסמנים **Auto Confirm User**. יוצרים ארבעה משתמשים:
   | מי | אימייל |
   |---|---|
   | מטיילת 1 | `t1@our-trip.app` |
   | מטיילת 2 | `t2@our-trip.app` |
   | מטיילת 3 | `t3@our-trip.app` |
   | מנהל | `admin@our-trip.app` |
   אחר כך, ב-**Table Editor > profiles**, משנים את `display_name` של כל אחת לשם שלה.
   הסיסמה לכל אחת היא מה שהיא תקליד בכניסה לאתר. האימיילים לא אמיתיים, הם רק מזהים.
5. **Project Settings > API**: מעתיקים את **Project URL** ואת המפתח **anon public**.

### 2. GitHub
1. מעדכנים את שני הערכים בקובץ `.env.production`.
2. **Settings > Pages > Source**: בוחרים **GitHub Actions**.
3. כל שינוי שנדחף ל-`main` מתפרסם אוטומטית לכתובת `https://<שם-המשתמש>.github.io/<שם-הריפו>/`.

### 3. בטלפון
פותחים את הכתובת ובוחרים "הוספה למסך הבית". האתר ייפתח כמו אפליקציה, והמסמכים יישמרו בטלפון כדי שיהיו זמינים בלי אינטרנט.

## הרצה מקומית
```
cp .env.example .env.local   # למלא את שני הערכים
npm install
npm run dev
```

## מה רואה מי
- **מטיילות**: הכול.
- **מנהל**: הכול, וגם פתיחה וסגירה של קפסולת הזמן (בדף "ניהול").
- **אורחים**: ספירה לאחור, תאריכים, המפה עם הסיפורים, ורק תמונות שסומנו "גלוי לאורחים".
- **קפסולת זמן**: מכתב שנחתם ננעל. אף אחת לא יכולה לקרוא, לערוך או למחוק אותו, גם לא מי שכתבה, עד שהמנהל פותח. ההגבלה נאכפת במסד הנתונים, לא רק במסך.
